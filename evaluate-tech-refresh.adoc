= Determine if a system refresh is recommended for your storage system in Digital Advisor 
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
If you want to identify whether a system refresh is recommended for your Tech Support contract or hardware, you can use the system refresh option.

You can access this feature either through Lifecycle planning (*Storage* > *Lifecycle planning*) or through Digital Advisor (*Dashboard > Planning widget > System Refresh*).

For more information about this feature, see link:https://docs.netapp.com/us-en/console-lifecycle-planning/use/tech-refresh.html[Evaluate a system refresh] in the Console documentation.
