= Discover Value Insights in Digital Advisor
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The Value Insights feature consolidates the overall health score, savings, stability, and security information for your E-Series, ONTAP, and StorageGRID systems. You can use this information to improve the system health score and performance through a continuous, data-driven view of your E-Series, ONTAP, and StorageGRID environment.

NOTE: Value Insights is available for E-Series, ONTAP, and StorageGRID systems. 

Value Insights provides the following information: 

* Overall health of your system is a health score metric made up of nine key performance indicators. Each section has a detailed KPI and score breakdown. 
* Savings and stability scores indicate how to achieve capacity and storage savings through efficient resource use. Access trend information regarding storage uptime and unplanned downtime, including the capability to download EMS files.
* Security and future planning details the risks avoided and issues prevented. Cost savings are calculated from storage efficiencies. 
* Maximize infrastructure value recommends additional features to further improve infrastructure performance for peak efficiency.
