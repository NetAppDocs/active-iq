= View risks for actions in Digital Advisor and mitigate using Unified Manager or Ansible Playbook
:toclevels: 1
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
You can analyze your storage system by viewing the actions and risks, and mitigate them using Active IQ Unified Manager or Ansible Playbook.

video::XusFvXM7h-E[youtube, width=848, height=480]

.Steps
. Select *View All Actions* on the dashboard.
. Select *Actions* to view the risks associated with the actions, select *Risks* to view all the risks, or select *Affected Systems* to view the systems that require attention.
+
If the risk can be mitigated using Active IQ Unified Manager, the image:spanner.png[Spanner] icon is highlighted and if the risk can be mitigated using Ansible Playbook, the image:update_ansible.png[Update Ansible] icon is highlighted.

[cols=2*,options="header", cols="50,50"]
|===
| To mitigate the risk using Unified Manager
| To mitigate the risk using Ansible Playbook
a|
. Select the image:spanner.png[Spanner] icon.
. Select *Fix It* to launch Active IQ Unified Manager.
. Select *Install* to install Active IQ Unified Manager 9.7 or later to use the *Fix It* option.
. Select *Upgrade* to upgrade to Active IQ Unified Manager 9.7 or later to use the *Fix It* option.
a|
. Select the image:update_ansible.png[Update Ansible] icon.
. Select *Download* to download the AFF and FAS firmware Ansible Automation package.
|===

NOTE: A SupportEdge Advisor or SupportEdge Expert contract is required to use the *Fix It* option and the Ansible Playbook features.
